Signal details & help

Uncheck Hold to set the state once without changing its cycle or current hold. Resume cycle releases a held intersection. A group contains multiple approaches. Each approach has several physical heads sharing movement indications. Lane references come from OpenDRIVE; turn protection comes from the phase program. Red may last longer while other approaches run. Pause stops the signal clock. Editing is disabled during recording or replay.

Routing help

Destinations can change while running. Select an actor, then click Destination and pick its new goal. Pause before spawning or changing sensors. Destination pins snap to drivable lanes for vehicles. Pedestrians snap to blue sidewalks or sampled walk points. Dashed pedestrian lines indicate the destination, not the actual navigation route. CARLA determines the walkable route.

EGO CONFIGURATION

Sensor loadout

All sensors capture every 0.05 simulation seconds. Names become ROS topic names. Loadout changes require a paused, non-recording world.

External planner connection

Send controls to POST /api/command/control with vehicle ID, throttle, steer and brake. Include X-Control-Client: carla-control-center.

ROS 2 domain 42. Topics: /carla/ego_ID/…, /clock, /tf. Controls older than one wall-clock second apply the brake.

SIMULATOR CONNECTION

Runtime

CARLA server on this host, port 2000. The web service owns synchronous stepping.

Automatic mode adds renderers when GPU sensors are configured and releases them when none remain. Each active worker still needs its own scene in RAM and GPU memory.

Parallel sensor processing

Pause first. Profiling advances the scene and captures 50 frames per worker count. It recreates sensor streams, preserves sensor quality, and cannot run during recording or replay.

Frame processing

Step or run to measure frame processing.

Physics: Chaos on CPU. World time includes physics, actor updates, replication and server communication. Sensor rendering and ray queries run on the GPU workers.

Use an existing server only when no other client owns its clock. Disconnect restores its prior settings. Start simulation launches a group owned by this service.
