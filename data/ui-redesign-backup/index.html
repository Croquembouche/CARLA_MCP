EGO CONFIGURATION

Sensor loadout

All sensors capture every 0.05 simulation seconds. Names become ROS topic names. Loadout changes require a paused, non-recording world.

External planner connection

Send controls to POST /api/command/control with vehicle ID, throttle, steer and brake. Include X-Control-Client: carla-control-center.

ROS 2 domain 42. Topics: /carla/ego_ID/…, /clock, /tf. Controls older than one wall-clock second apply the brake.
